Eka Lymar — готовая версия для GitHub Pages.

Загрузите содержимое этого архива в корень репозитория, выбранного для GitHub Pages. Файл index.html должен лежать в корне, рядом с папкой assets и файлом hero-mask.png. Пути относительные, поэтому сайт работает и по адресу вида username.github.io/repository/.
