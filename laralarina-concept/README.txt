Концепт сайта студии ресниц

Откройте index.html в браузере.

Файлы:
- index.html — разметка
- styles.css — стили, адаптивная вёрстка
- script.js — данные карточек и взаимодействия
- assets/hero.png — прикреплённая вами фотография

Для GitHub Pages загрузите папку целиком в репозиторий. Пути к файлам относительные, поэтому сайт работает и в подпапке.

Реальная ссылка для записи не предоставлена: кнопки открывают демонстрационное сообщение.
Изменить названия, цены и описания услуг можно в массиве services в script.js.
